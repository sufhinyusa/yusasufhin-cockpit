# yusasufhin-cockpit — 7/24 Bulut Web Kokpiti & Yapay Zeka Ağ Geçidi

Bu depo, `https://yusasufhin.com/` alan adını bilgisayarınız kapalıyken bile 7/24 ayakta tutan, Render üzerinde çalışan bağımsız bulut ağ geçididir.

## Özellikler
- **Bulut Web Kokpiti:** Fast API ve Uvicorn altyapısıyla 7/24 bulut üzerinde çalışır.
- **PWA & Mobil Uyumlu:** Cep telefonundan ana ekrana eklenebilir mobil arayüz.
- **OmniRoute Şelalesi:** Ücretsiz katman yapay zeka modelleri için akıllı yönlendirme (Kota durumuna göre simülasyon etiketi içerir).
- **GPU İşçi Kuyruğu:** Kaggle / Colab GPU işçileri bağlandığında render ve ses üretimini yürüten kuyruk biletleme yapısı.
- **Anti-Slop Humanizer:** Kural tabanlı robotik yapay zeka kalıplarını temizleyen metin arındırıcı.
- **Web Kokpiti:** Canlı WebSocket bildirim köprüsü ve korumalı yönetim paneli.
